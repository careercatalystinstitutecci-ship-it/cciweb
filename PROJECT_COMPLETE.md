## 🚀 Quick Start (3 Steps)

### Step 1: Install Dependencies
```bash
cd Careercat
npm install
```

### Step 2: Start Development Server
```bash
npm run dev
```
Website opens automatically at `http://localhost:5173`

### Step 3: Build for Production
```bash
npm run build
```
Optimized build created in `dist/` folder
